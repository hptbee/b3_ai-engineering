# Cursor Subagents (official docs)

## Source

https://cursor.com/docs/context/subagents

## Tier

Tier 1

## Purpose

Define specialized delegated agents with isolated context for complex, parallel, or noisy work.

## Architecture

Parent agent launches subagent with prompt + context slice. Subagent returns final message. Built-in: Explore, Bash, Browser (context isolation, specialized models/tools). Custom subagents: markdown + YAML frontmatter in `.cursor/agents/` (also `.claude/agents/`, `.codex/agents/`).

## Important Patterns

- Foreground vs background execution modes
- Context isolation for verbose intermediate output
- Model override per subagent (`model: inherit|fast|…`)
- `readonly: true` for audit-style roles
- Decision table: subagent vs skill

## Skill Design

Skills for single-shot repeatable tasks; subagents for multi-step isolated work or verification independence.

## Rules / Instructions

Subagent file body is the role prompt. Frontmatter: `name`, `description`, optional `model`, `readonly`.

## Agents

This **is** the agent specialization layer for Cursor. Precedence: `.cursor/agents/` over `.claude/` / `.codex/` on name collision.

## Commands / Workflows

Agent auto-delegates; users can request custom subagent creation via natural language (`Create a subagent file at .cursor/agents/verifier.md…`).

## Evaluation

No formal evals. Built-in subagents chosen from analysis of context-limit failures in production conversations.

## Portability

Role **intent** portable (security reviewer, verifier); file format and hook integration host-specific.

## Strengths

- Explicit when to use subagents vs skills
- Built-in subagents encode real operational lessons (noise, parallelism)
- Cross-compat paths for Claude/Codex agent folders

## Weaknesses / Trade-offs

- Easy to over-subagent simple tasks
- Independent subagents still share parent orchestration blind spots unless carefully prompted
- No standard finding schema across custom subagents

## Interesting Implementation Details

- Explore subagent defaults to faster model for parallel search
- Subagents start with **clean context** — parent must pass necessary state

## Relevant Files

- `.cursor/agents/*.md` format documented in doc
