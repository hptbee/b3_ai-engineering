## `b3-guard` subcommands

| Subcommand | Exit codes | What it does |
| --- | --- | --- |
| `fingerprint` | `0` ok, `1` bad args | Emits canonical `depends_on=<sorted ids or []>\|scope=<trimmed>\|acceptance_criteria=<; joined>` |
| `check-freshness` | `0` `FRESH`, `2` `STALE`, `1` error | Verifies `HEAD` descends from `task_base`, committed `watched_paths` untouched, and uncommitted `read_only_deps` untouched |
| `precommit` | `0` `PRECOMMIT_OK`, `1` fail | Rejects mid-operation Git state, empty staging, `.b3/{ship,autodev}/` checkpoints, un-exact secret paths, undeclared paths; with `-RequireVerifyReceipt`/`--require-verify-receipt`, also checks `staged == WT`, validates receipt freshness, verifies staged paths stay inside receipt scope, and rejects unstaged/untracked changes inside receipt scope (preventing partial staged bypasses) |
| `snapshot` | `0` SHA, `1` error | Builds an isolated temporary-index tree including nonignored untracked files without changing the real index/stash; fails closed before writing sensitive-path blobs or when submodules have dirty/untracked contents |
| `diff-scope` | `0` summary (including `CLEAN_AFTER_FIX` with snapshot delta), `2` initial/unchanged `EMPTY_DIFF`, `1` error | Rename-safe (`--no-renames`), excludes `.b3/ship/`, `IgnoreDirtyPaths`, and lockfile/generated noise; `-BaseSha`/`--base-sha` defaults to `auto`; optional `-TargetRef`/`--target-ref` diffs a commit/ref without touching WT; outputs T-shirt `size_class` (`XS`..`XXL`, `NOISE_ONLY`, `CLEAN_AFTER_FIX`), `files`, `lines`, `review_files`, `noise_files`, optional `delta_files`, plus decoupled `risk_level`, `risk_signals`, and `recommended_specialists` |
| `review-inventory` | `0` summary, `2` `EMPTY_DIFF`, `1` error | Level-0 deterministic inventory (`0 LLM tokens`): outputs scope size/risk, `change_types`, `contract_files`, `generated_files`, `test_files`, `split_recommended`, clamped `max_concurrency` (`1..4`), and cohesive module+test `unit\|U0N\|...` slices with per-unit risk and specialist triggers |
| `review-ledger` | `0` ok/`LEDGER_GATE_PASS`, `2` `LEDGER_INCOMPLETE`/`LEDGER_STALE`/`LEDGER_BLOCKED`, `1` bad args/missing/corrupt | Fail-closed `b3-review-ledger-v1` coverage/evidence ledger (`--action init\|update\|normalize\|check`): checks safe snapshots, normalizes legacy size labels (`SMALL\|MEDIUM\|LARGE\|VERY_LARGE`), tracks unit/cross-unit coverage, specialists/rationales, verify receipts, budgets, and invalidates stale units when code, shared contracts, or risk change |
| `mechanical-check` | `0` `MECHANICAL_OK`, `2` `MECHANICAL_FINDINGS`, `1` error | Deterministic pre-review audit (`0 LLM tokens`): checks `scope_creep` against `AllowedPaths`, added-line `leftovers`, `obsolete_hits`, and `safety_hits` (secrets, destructive SQL on non-test/non-`.md` code, mass deletion `>= 10f` unless `-AllowMassDelete`/`--allow-mass-delete`) |
| `symbol-check` | `0` `SYMBOL_OK`, `2` `SYMBOL_FINDINGS`, `1` error | Extracts added/removed code declarations across `-U0` diff + untracked files; reports `removed_symbols`, `exported_removed`, `dangling_refs`, and non-exported `orphan_internal` (never flags exported APIs as internal orphans) |
| `verify-run` | `0` `VERIFY_PASS`, `1` `VERIFY_FAIL`/error | Runs verification command cleanly in `RepoRoot`, logs failures or `>35`-line output to `LogPath` (`<receipt>.log`), and writes atomic `b3-verify-v1` receipt bound to `head_sha` + effective `tree_hash` (`git ls-tree` + working-tree/index overlay capturing entry mode, type, object identity/content, and submodule commit/dirty state, stderr-isolated) |
| `verify-check` | `0` `VERIFY_VALID`, `2` `VERIFY_STALE`, `1` missing/corrupt/mismatch/fail | Validates `b3-verify-v1` receipt provenance (`command`, `log_path` repo-containment + existence, `timestamp_utc`), pass status, optional `-ExpectedCmd` (`VERIFY_MISMATCH`), optional `-RelevantPaths` coverage (`VERIFY_SCOPE_MISMATCH`), forward commit ancestry (`merge-base --is-ancestor`), and effective mode/type/content/gitlink `tree_hash` |
| `check-wave` | `0` `WAVE_OK`, `2` `WAVE_CONFLICT` / `WAVE_BASE_MISMATCH`, `1` error | Validates pairwise exact + prefix write-write disjointness, optional `-WaveReads`/`--wave-reads` read-write conflicts (`rw:`), and optional `-ExpectedBaseSha`/`--expected-base-sha` + mid-operation safety |
| `check-worktree` | `0` `WORKTREE_OK`, `2` `WORKTREE_UNSAFE`, `1` error | Verifies valid Git worktree, clean of mid-repo ops, matching `-ExpectedRoot`/`--expected-root` (same top-level or linked `--git-common-dir`), and matching `-ExpectedBaseSha`/`--expected-base-sha` |
| `new-run` | `0` `<run_id>`, `1` error | Allocates `.b3/ship/runs/<YYYYMMDD-HHMM>-<slug>/` (with `-2` collision suffix) and writes `.b3/ship/CURRENT` atomically |
| `resolve-run` | `0` path, `1` `NO_ACTIVE_RUN`/error | Resolves `.b3/ship/runs/<id>` from `-RunId`/`--run-id` or `CURRENT` (with legacy `.b3/ship` and read-only `.b3/autodev/` fallbacks) |
| `list-runs` | `0` list | Lists runs newest-first with `[<run_status>]` and `*` marker on `CURRENT` (plus legacy `(legacy-autodev)` fallback when `.b3/ship/` has no runs) |
| `prune` | `0` `PRUNE_OK`, `1` error | Keeps newest `Keep` (default `10`) `PASS` runs; never deletes `CURRENT` or non-`PASS` runs |

### Receipt migration (`b3-verify-v1`)

Legacy `b3-verify-v1` receipts generated before mode/type/gitlink fingerprinting retain the same schema and header fields, fail closed with `VERIFY_STALE` (exit `2` on `verify-check`, exit `1` `PRECOMMIT_FAIL` wrapping `VERIFY_STALE` on `precommit -RequireVerifyReceipt`), and auto-migrate cleanly when re-verified via `verify-run` (no manual receipt deletion or schema migration step required). Staged-vs-working-tree blob synchronization continues to be enforced by `precommit` while `verify-check` verifies effective working state plus index presence/mode divergence.
