# Profiles

Personal engineering context for the owner of this system. Not universal engineering truth.

```text
Personal preference  ≠  Engineering rule
```

```text
Personal Profile
      ↓
Personal Preferences
```

This is contextual guidance. It must **never** override:

- security requirements
- correctness
- explicit project requirements
- hard repository rules
- platform / tool constraints

Full order: [`docs/precedence.md`](../docs/precedence.md).

**Present:** placeholder profile [`tung/`](tung/engineering-style.md). Files explain their purpose; they are not a complete self-assessment.

Durable lessons from real work belong in `knowledge/personal/` with metadata. Background stack notes: [`../knowledge/personal/engineering-context.md`](../knowledge/personal/engineering-context.md). Do not duplicate those into every profile file.
